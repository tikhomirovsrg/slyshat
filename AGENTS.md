# Слышать — инструкции для работы с проектом

Учебный сайт для русскоязычных пользователей: английский и итальянский, основной сценарий — истории и понимание речи на слух. Сохраняйте спокойный зелёный интерфейс и существующий прогресс.

## Устройство
- Next.js App Router, React, TypeScript; Node.js 24. `app/page.tsx` — оболочка, `app/episodes.ts` — интерактивные истории.
- `lib/db-migrations.mjs` — последовательные транзакционные миграции SQLite. `lib/db.ts` — подключение. Docker запускает миграцию до сервера.
- `app/speech.tsx` / `lib/speech-player.ts` — общий владелец воспроизведения. Новый звук останавливает старый. Не создавайте независимую конкурирующую озвучку.
- `public/audio/` — готовые записи; `scripts/audio-library/` — воспроизводимая генерация большого каталога. Синтез и скачивание весов не нужны для запуска сайта.
- Yandex ID — серверная авторизация; прогресс и профиль синхронизируются через существующие API.

## Правила
1. Не меняйте байты применённых `content/catalog-v1.json` и `content/practice-v2.json`. Новые материалы — новый версионированный выпуск, без сброса данных пользователей.
2. Различайте интерактивные истории, сценарные варианты, планы и реально готовые записи. Не приписывайте каталогу отсутствующий контент.
3. A1–C1 — педагогические ориентиры. Сложность определяется языком и заданиями, а не скоростью воспроизведения; официальной сертификации CEFR нет.
4. Открытый текст означает помощь чтением. Прослушивание, правильный ответ и освоение урока — разные события. Прерванное воспроизведение не завершает аудирование.
5. Не отправляйте пользовательские черновики в синтез; не добавляйте ключи, `.env`, БД, бэкапы, модели и виртуальные окружения в Git. Секреты остаются на сервере.
6. Публикация в GitHub и обновление пользовательского Docker-сервера — разные действия. Сообщайте, какое реально выполнено.

## Проверка
`npm run check`, `npm test`, `npm run build`, затем `npm run test:production`.
Не запускайте TypeScript-проверку одновременно со сборкой Next: `.next/types` перезаписывается.
Для аудио проверяйте ссылки, контрольные суммы, длительности, остановку, переключение и завершение. Техническая проверка не заменяет прослушивание носителем.
Docker: смотрите `compose.yaml`, `Dockerfile`, `docs/OPENCLAW-NEXT.md` и актуальные документы в `docs/`.
