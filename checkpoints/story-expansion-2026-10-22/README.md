# Промежуточное сохранение разработки

По просьбе владельца текущая работа сохранена в `main` до завершения озвучки.
Это восстанавливаемый снимок **55 файлов**, включая код интеграции, исследования,
**218 новых написанных историй**, задания, словарь, генератор аудио и тесты.
Цель остаётся прежней: 246 новых + 54 сохранённые истории, по150 на язык.

Снимок не активирует незавершённый каталог. Файлы рабочего приложения в корне
репозитория продолжают соответствовать родительскому коммиту. Это позволяет
сохранить работу сейчас без публикации неполного аудио или сломанной сборки.

В `checkpoint.json` записаны все пути, размеры, SHA-256, фактические количества,
состояние генерации и адрес отдельной ветки передачи прежней озвучки. Три части
архива составляют один `tar.gz`; порядок и контрольные суммы заданы манифестом.
Модели, PCM-кеш, виртуальное окружение, секреты, базы и `node_modules` в снимок
не входят. Новую озвучку можно повторить по сохранённым сценариям и генератору.

Проверить целостность:

```bash
python3 checkpoints/story-expansion-2026-10-22/restore.py
```

Восстановить в отдельную чистую рабочую копию:

```bash
git worktree add -b recovery/story-expansion ../slyshat-recovered f9360ede40aa0c5887b714fd06c0eaf9612eb524
python3 checkpoints/story-expansion-2026-10-22/restore.py --destination ../slyshat-recovered
```

Восстановление проверяет исходное дерево, чистоту рабочей копии и каждый файл.
Оно не запускает приложение, генерацию или публикацию. После восстановления
нужно завершить недостающие истории, независимую редактуру, озвучку и полный
прогон `check`, `test`, `build`, `test:production` перед активацией выпуска.

Последнее уточнение владельца: создавать самостоятельные учебные аналоги,
не копировать чужие тексты или современные переводы и не ограничиваться
заменой имён. Источники исследований сохраняются для честной проверки
происхождения идей. Новые реплики, русские переводы, упражнения и финалы
написаны для этого проекта.
