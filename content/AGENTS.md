# Учебные материалы

Сохраняйте старые ID и неизменяемые выпуски: от них зависят ответы, черновики и миграции установленных экземпляров.

- `catalog-v1.json`: 200 строк исходного плана, из них 40 интерактивных историй; оставшиеся планы не являются готовыми уроками.
- `practice-v2.json`: дополнительная практика; не менять опубликованный файл без нового releaseId.
- `audio-library/`: отдельная серия сценарных аудиовариантов. Количество вариантов не равно количеству независимых сюжетов. Храните происхождение и структуру серии открыто.
- Для каждого языка нужны уровни A1, A2, B1, B2, C1. Развивайте лексику, синтаксис, выводы и аргументацию. Не присваивайте уровень только по числу слов.
- Объяснения, вопросы и переводы — по-русски; речь персонажей — на языке занятия. Правильный ответ обязан следовать из материала, а объяснение — раскрывать основание ответа.
- Поля готовности аудио выставляются только после создания и проверки файлов. Число планов не включать в число готовых записей.
- Не создавайте тысячи «новых сюжетов» заменой имён: называйте переиспользующие сцены материалы вариантами и показывайте это пользователю.

- `story-course/` — комиксы с реальным выбором продолжения и финала. Старые ID включены в общий порядок, дополнительные материалы сохраняются. Каждая новая ветвь обязана быть достижима; все маршруты заканчиваются осмысленным исходом.
