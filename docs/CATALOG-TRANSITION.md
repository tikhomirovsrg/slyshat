# Переход на отобранный каталог

Активный каталог содержит 300 историй: по 150 на язык и по 30 на каждый уровень A1–C1. В нём 54 сохранённые истории и 246 новых. Отобранные сюжеты и исходные ID задаются отдельным выпуском `content/story-curation/v1.json`; новые диалоги находятся в `content/story-expansion/v1/`.

## Что видит пользователь

- Каталог, фильтры, рекомендации и счётчик прогресса используют активные 150 историй языка.
- Старые 1946 вариантов доступны по исходному ID. Начатые и завершённые появляются в «Ранее начатых историях», незавершённую активную историю можно продолжить. Новое прохождение не переносится на похожий ID.
- У каждой новой истории есть состав из двух людей, три выражения перед началом, две развилки и четыре задания по пройденной ветке. Общие рисунки персонажей и декораций переиспользуются.
- Новые истории имеют отметку Reading / Lettura: новой опубликованной озвучки нет. Реплики показаны сразу, текст ответа находится на кнопке выбора. Прослушивание не засчитывается за чтение.
- После финала можно выполнить вопросы и перечитать только нужные реплики своего маршрута. Открытие фрагмента отмечает помощь чтением. Результат задания не является оценкой уровня CEFR.

## Сохранения и запуск

Неизменяемые выпуски `catalog-v1`, `practice-v2`, `course-v1`, `comic-v1`, `cast-v1` не переписываются. SQLite остаётся на схеме 8; 2000 строк прежнего курса в БД — историческое хранилище, а не число активных карточек. В профиле разрешены все 2246 исходных и новых ID, включая прежние результаты упражнений. Обновление выполняется обычной пересборкой контейнера с сохранением текущего тома и секретов.

```sh
git pull --ff-only
docker compose up -d --build app
```

Не удалять том, не сбрасывать БД. Проверка рабочего сервера:

```sh
curl 'https://tikhomirovsrg.ru/api/stories?language=en'
curl 'https://tikhomirovsrg.ru/api/stories?language=it&includeArchived=1'
```

Ожидается `total: 150`, уровни по 30; с `includeArchived=1` — отдельные 973 архивных карточки. У новых деталей `audioMode: "text"`, пустой `source` у реплик, явные actorId и авторские задания. Сохранения старых ID продолжают приниматься API.

## Проверки выпуска

`npm run check`, `npm test`, `npm run build`, `npm run test:production`.

Сборка дополнительно проверяет полный набор 246 новых историй, достижимость веток, словарь, привязку заданий к репликам, совпадение с планами и точные повторяющиеся длинные фрагменты. `node scripts/story-expansion/audit-plans.mjs` формирует очередь похожих замыслов для ручного просмотра. Технические отпечатки и длина текста не доказывают отсутствие сюжетных дублей или уровень CEFR: редакторский разбор и его границы описаны в `docs/audits/catalog-transition-editorial-review.md`.

Реплики и переводы написаны для проекта; исследовательские источники и характер переработки сохранены. Это не подлинные тексты названных классических авторов и не юридическая сертификация. Некоторые сохранённые истории используют общие нейтральные завершающие сцены; разные сюжетные конфликты не означают уникальность каждого рисунка или каждой строки.

## Озвучка

Без `public/audio/expansion/manifest.json` каталог работает в режиме чтения. Если manifest присутствует, требуется полный выпуск: совпадающий хеш текста, назначенные говорящие, все реплики/ответы, существующие файлы и корректные границы. Неполный или устаревший выпуск не считается готовым. `npm run stories:audio:validate` строго проверяет готовую озвучку; `npm run stories:audio:check` разрешает её отсутствие.

Сценарий будущей генерации — `scripts/story-expansion/audio.py`; веса, кеш, временные PCM и секреты не входят в Git. Неполная историческая передача в `audio-checkpoints/` не является новым выпуском и не активируется автоматически.
