# Промежуточное сохранение выпуска 3.3

Этот коммит сохраняет уже сделанную работу по просьбе владельца. Он не означает завершения новой озвучки или обновления работающего сервера.

Готовы составы человеческих персонажей для всех 2000 историй, шесть комплектов иллюстраций, озвучиваемые варианты ответа и воспроизведение выбранного диалога в интерфейсе. Четыре задания формируются для каждого из 8125 завершённых маршрутов, результаты сохраняются отдельно от сюжетных решений.

Новые записи Kokoro ещё генерируются. До появления полного `public/audio/characters/manifest.json` сайт продолжает проигрывать прежние файлы `course` и `library`; для ещё не опубликованных записей ответов показывается текстовый вариант с учётом помощи чтением. Неполный набор не объявляется готовым аудиовыпуском.

Снимок проверенных WAV и метаданных кэша сохранён локально и передаётся в GitHub отдельно от этого кодового checkpoint. В этой ветке каталога `audio-checkpoints/character-pcm-v1/` и аудиоархива ещё нет. Отдельный снимок сохраняет 1009 из 2512 задач (2 ч 17 мин 33 с речи); контрольные суммы указаны в его манифесте. Это промежуточный снимок, а не актуальный счётчик продолжающегося процесса. Модели, виртуальное окружение, пользовательские данные и ключи в него не входят. Каталог снимка исключён из Docker-контекста.

Инструкции восстановления находятся в README отдельного снимка и будут доступны вместе с ним. Генератор повторно проверяет точный текст, голос, скорость, версии модели и SHA-256 WAV перед повторным использованием. Он создаёт только недостающие записи. Публикация итогового аудиоманифеста возможна лишь после подготовки и проверки полного набора.

Проверка типов и 94 теста прошли до промежуточного сохранения. Production-сборка также прошла. В рабочей среде отсутствует `/proc`, поэтому только для запуска проверки использован внешний адаптер системной метрики Node: пиковая RSS из `process.resourceUsage()` вместо недоступной текущей RSS. Адаптер не входит в код приложения. Полный выпуск дополнительно требует production-сборки, HTTP-проверок и полного декодирования новых MP3.

`npm run character-audio:validate` требует готовый полный выпуск. `npm run character-audio:check` разрешает только его полное отсутствие для промежуточной версии; присутствующий повреждённый или неполный манифест отклоняется обоими режимами.

Production HTTP-проверка промежуточной версии также прошла: иллюстрации, сохранение заданий между сессиями и перезапуском, экспорт и восстановление SQLite проверены. После добавления новых MP3 эту проверку нужно повторить уже с полным аудиовыпуском.
