# Исторический выпуск 3.2 — рисованные истории

Релиз добавляет постановку для всех 2000 записей курса: 14 138 сцен. Каталог содержит по 1000 историй и вариантов на язык; число самостоятельных сюжетов не увеличивалось. Озвучка, тексты, графы, старые ID и порядок неизменны.

## Персонажи и художественное направление

Решение для исторического выпуска 3.2: **все герои — необычные антропоморфные животные**. В выпуске 3.3 по новому решению владельца их заменяют люди: см. [CHARACTERS.md](CHARACTERS.md). Они одеты, работают, путешествуют, спорят и дружат как люди. Выразительные животные морды, уши, клювы и лапы сохраняются. Стиль — приключенческий графический роман для взрослых: тушь, бумажная фактура, тёплые охристые и терракотовые цвета, тёмно-бирюзовые контуры. Байты ресурсов 3.2 сохраняются для совместимости; человеческие ресурсы 3.3 добавляются отдельным выпуском.

Первые два визуальных актёра:
- Лиса-путешественница: терракотовая куртка, сумка с билетами, компас. Любопытная и деятельная.
- Ворон-картограф: бирюзовое пальто, охристый шарф, очки, карта и блокнот. Наблюдательный, немного ироничный.

По четыре позы: слушает, говорит, думает, радуется. Эти актёры играют разные роли в имеющихся диалогах; имена и речь исходных персонажей сохранены. Это два общих дизайна, не 2000 уникальных составов героев. Новые виды добавлять с постоянными одеждой, силуэтом, палитрой и характером; сохранять назначение героя внутри одной истории.

Восемь общих локаций: кафе, вокзал, площадь, дом, рабочая мастерская, сад у реки, культурное пространство, рынок. Это условные декорации; например, домашняя декорация также используется для гостиничных сюжетов. В дальнейшем таким сюжетам нужны отдельные интерьеры. Изображения созданы ImageGen. Точные запросы, происхождение, размеры и SHA-256 интегрированных файлов: `public/comics/v1/manifest.json`. Готовые WebP: `public/comics/v1/`. Оригиналы генерации не требуются серверу.

## Работающий сценарий

1. Иллюстрированные обложки, короткая завязка и фильтр по четырём тематическим сериям помогают выбрать историю. Нумерация курса и продолжение по порядку сохранены.
2. У каждого узла своя постановка: локация, крупность, поза, подпись, предмет. Для `coffee-it` вручную описаны все 13 кадров, включая три финала. Остальные постановки собираются из 25 тематических профилей и исходных сцен.
3. Во время настоящего воспроизведения выделяется говорящий актёр, меняется поза. Позиция берётся из аудио, а не из самостоятельного таймера анимации. Скорость 0,5–1,5× не сбрасывает запись. Это переключение поз, не фонемная анимация губ.
4. Кнопка «Осмотреть» с предметом открывает перевод **текущей** сцены. Это помощь чтением, без баллов за аудирование. Новый квест или дополнительный предмет инвентаря не создаётся.
5. Под кадром виден предыдущий выбор. Полный маршрут можно раскрыть. Решения продолжают влиять на существующий граф и финал.
6. В коллекции можно раскрыть уже открытый финал. Названия, иллюстрации и тексты неоткрытых финалов не выводятся. «С начала» очищает текущую попытку, сохраняя коллекцию и первое завершение.
7. Есть статичный режим и поддержка системного reduced motion. Переключатель движения относится к текущему открытому комиксу; отдельно в аккаунт эта настройка не сохраняется. Действия доступны с клавиатуры и не требуют движения или наведения мыши.

## Данные и обновление

Схема SQLite 7 добавляет `comic_releases` и `comic_boards`. Миграция автоматически строит 2000 полных постановок из `content/comics/comic-v1.json`, неизменяемого курса и его переводов. Проверяются версия и SHA-256 курса. Повторный запуск ничего не перезаписывает. Новый визуальный выпуск должен иметь новую версию и миграцию; нельзя редактировать опубликованный рецепт v1 в `lib/comic-migration.mjs`.

Docker включает JSON, миграцию и изображения. Генерация иллюстраций и ключи ImageGen на сервере не нужны. Пользовательские маршруты, черновики, завершения и открытые финалы сохраняются прежним механизмом Yandex ID. Резервная копия схемы 7 содержит постановки вместе с прогрессом; старые схемы 1–6 поддерживаются восстановлением и последующей миграцией.

## Проверка и дальнейшее развитие

`npm run comics:validate` проверяет все кадры, допустимые локации/позы/предметы, точное соответствие подсказки текущим репликам и контрольные суммы изображений. Он входит в `prebuild`. Дополнительно: `npm run check`, `npm test`, `npm run build`, `npm run test:production`.

Автоматически проверяются миграция 6 → 7 и откат при ошибке, сохранность профилей, скрытые финалы, классификация чтения, аудиопозиция при изменении скорости, реальная HTTP-выдача изображений, повторный запуск и backup/restore. Браузерная проверка на реальном телефоне остаётся отдельным этапом: осмотреть 360/390/768 px, увеличение текста, клавиатуру, загрузку звука в Safari/Chrome и отсутствие перекрытия лиц кнопками.

Следующий содержательный этап — 10 индивидуально поставленных сюжетов (6 итальянских, 4 английских) с собственными событиями и иллюстрациями последствий; затем расширение по результатам пробного прохождения. Для удержания проверять, понятны ли решения, замечают ли последствия, возвращаются ли к другим финалам. Текущий релиз не включает систему аналитики и не доказывает рост удержания. Тысячи вариантов не заменяют редактуру и тестирование интереса к самим историям.
