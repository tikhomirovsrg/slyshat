# Расширение практики 2.2 — 20 октября 2026

Этот документ описывает выпуск практики 2.2 и его миграцию 3 → 4. В текущем приложении после него применяется [миграция аудиобиблиотеки до схемы 5](AUDIO-LIBRARY.md); команда проверки поэтому показывает `schemaVersion: 5`.

Центр занятия — интерактивная история. Новый выпуск добавляет задания к существующим историям и не увеличивает обязательную часть уже освоенного урока.

Входные тесты и контрольные выбирают задания из банка, а не создают дополнительные уникальные задания. Количество готовых ветвящихся историй остаётся 40; 160 записей каталога по-прежнему являются планом.

## Что подсказали источники

Проверено 20 октября 2026. Учебные сцены и задания этого выпуска написаны специально для проекта. Чужие задания, ключи, тексты и аудиофайлы не скопированы.

1. [British Council / TeachingEnglish: A framework for planning a listening skills lesson](https://www.teachingenglish.org.uk/professional-development/teachers/planning-lessons-and-courses/framework-planning-listening-skills). Подготовка контекста, первое понимание смысла, повторное слушание ради деталей, затем применение и разбор языка. В проекте: описание ситуации перед блоком, вопросы к разным коротким сообщениям, диктант и выбор уместного ответа. Повторное прослушивание доступно без штрафа.
2. [Совет Европы: CEFR Companion Volume, глава о коммуникативных действиях](https://rm.coe.int/chapter-3-communicative-language-activities-and-strategies/1680a084b4). На начальных уровнях важны знакомые ситуации и конкретная информация; далее — причины, условия, позиции и неявные отношения. В проекте A1–A2 сосредоточены на времени, месте и договорённостях; B1 — на последовательности и причинах; B2–C1 — на оговорках, аргументации и различии между фактом и предположением. Метки являются редакционными ориентирами, а не валидированной сертификацией CEFR. Короткая реплика не заменяет проверку понимания длинной речи C1.
3. [Università per Stranieri di Siena / CILS: примеры B1](https://cils.unistrasi.it/1/89/197/Prove_Liv._B1.htm) и [A2](https://cils.unistrasi.it/1/89/196/Prove_Liv._A2_standard.htm). Официальные комплекты разделяют аудио, расшифровки, задания, ключи и критерии оценки. В проекте аудиотекст скрыт до запроса, закрытые ответы получают ключ и объяснение, а письмо остаётся самостоятельной оценкой по критериям. Это учебная практика по историям, не копия экзамена CILS.

4. Для проверки грамматических объяснений: Treccani — [будущее в прошлом](https://www.treccani.it/enciclopedia/futuro-nel-passato_%28La-grammatica-italiana%29/) и [уступительные конструкции](https://www.treccani.it/vocabolario/concessivo/). В заданиях явно указывается требуемое время или наклонение, когда иначе возможны несколько форм.

Это обоснование проектных решений, а не утверждение о доказанной эффективности именно нашей платформы. Отдельное исследование результатов учеников пока не проведено.

## Доступ к новым заданиям

Открой историю → учебный блок «Разобраться глубже» → вкладка «Ещё практика».

- На итальянском: три блока по четыре вопроса — «Услышать и ответить», «Разобрать язык», «Продолжение истории».
- На английском: один блок из четырёх аудиозаданий к каждой истории.
- Каждый блок рассчитан примерно на 6 минут; его можно пройти отдельно. Три блока итальянского дают дополнительное занятие примерно на 18 минут.
- В новом выпуске 160 аудиозаданий, включая 40 коротких диктантов; 60 грамматических заданий, 20 лексических и 80 вопросов к 20 новым итальянским текстам.
- Ответы, ошибки и признаки использования аудио/текста сохраняются в обычном прогрессе истории. После входа через Яндекс они синхронизируются между устройствами.
- У дополнительных блоков свой счётчик. Они не меняют знаменатель 80% для основного урока и не отнимают старое освоение.
- Источник доступен рядом с вопросами на чтение, включая контрольные и повторение ошибок.
- При новых попытках контрольной набор меняется; полностью независимой оценкой уровня повторение знакомого материала не является. Входной тест и ключи старых тестов сохранены.

## Подсчёт и честные ограничения

Если расшифровка открыта, результат аудиозадания учитывается в чтении даже после воспроизведения. Прослушивание засчитывается после окончания реплики. Для старых сохранений без новых метаданных не предполагается самостоятельное аудирование. Регистр, пробелы, тип апострофа и конечная пунктуация не мешают проверке; в диктантах также допускается различие в запятых. Акценты и значимые окончания проверяются.

Аудио пока использует синтез речи устройства с выбранным голосом и скоростью; студийных записей и автоматической оценки произношения нет. Реплики в этих дополнительных блоках озвучиваются одним голосом; ветвящийся диалог основной истории остаётся отдельным сценарием. Свободное письмо не получает фиктивную оценку грамматики от счётчика слов. Материалы требуют дальнейшего независимого редакторского просмотра и калибровки с учениками.

## Данные и обновление

`content/catalog-v1.json` неизменен. Команда `content:build` теперь проверяет его соответствие исходной версии вместо перезаписи. Новый неизменяемый выпуск — `content/practice-v2.json`, `releaseId: practice-expansion-v2`. Этот же JSON импортируется клиентом.

Миграция схемы 3 → 4 создаёт `content_practice_sets` (80 блоков, полные вопросы и объяснения) и `content_practice_releases` (контрольная сумма, дата, количество). В одной транзакции проверяются ссылки на истории и загружаются новые блоки. Повторный запуск не создаёт дубли и не перезаписывает редакторские правки. Изменение файла с прежним `releaseId` останавливает миграцию. Таблицы пользователей, сессий, результатов и черновиков не переписываются. Старые резервные копии схем 1–3 обновляются при следующем запуске; восстановление схемы 4 поддерживается.

Интерфейс по-прежнему получает материалы из файлов сборки. Прямое редактирование JSON внутри БД пока не меняет интерфейс; API каталога и редактор — отдельный этап. Выпуск новых или исправленных материалов требует следующей явной версии миграции, а не редактирования уже применённого файла.

### Для OpenClaw

1. В действующем каталоге проекта проверь локальные изменения и сохрани резервную копию работающей SQLite вне контейнера по README.
2. Обнови `main` через `git pull --ff-only`. Сохрани существующие `.env`, имя Compose-проекта и том `progress_data`.
3. При внешнем reverse proxy выполни `docker compose up -d --build app`. При Caddy из этого Compose — `docker compose --profile https up -d --build`.
4. Повторно запусти `docker compose exec -T app node scripts/migrate.mjs`: ожидаются `schemaVersion: 4`, `seeded: false`, `practiceSeeded: false`, `practiceSets: 80`, `practiceQuestions: 320`.
5. Войди через Яндекс, открой итальянскую историю → «Ещё практика». Проверь один ответ, ошибку, открытие расшифровки и продолжение на втором устройстве. Проверь, что прежние черновики и освоенные уроки сохранились.

Не удаляй тома и не загружай старый бэкап при каждом старте. Для отката приложения, не поддерживающего схему 4, нужна сохранённая база до обновления.
