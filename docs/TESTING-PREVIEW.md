# Проверка историй без входа

После обновления сайта откройте `/?preview=1` — тот же каталог, комиксы, готовые записи и задания с отдельным тестовым прохождением.

- Итальянский каталог: `/?preview=1&lang=it`.
- Конкретная история: `/?preview=1&lang=it&story=coffee-it`.
- Английская история: `/?preview=1&lang=en&story=coffee-01`.

Язык прямой ссылки согласуется с самой историей. При открытии карточки или следующей истории ссылка обновляется, поэтому страницу можно перезагрузить или передать для воспроизведения ошибки.

Тестовый прогресс хранится под отдельным ключом `slyshat-preview-v1` в `sessionStorage` этой вкладки. При недоступном хранилище прохождение работает в памяти до перезагрузки. Кнопка сброса очищает только тестовое прохождение; ссылка «Вернуться на сайт» открывает обычный режим. Тестовые данные не переносятся в аккаунт.

Параметр выбирает отдельный клиентский экран, не создаёт сессию и не запускает синхронизацию аккаунта. Приватные API профиля, прогресса и серверного синтеза по-прежнему требуют входа; каталог историй и готовые MP3 уже публичные.

Для проверки пройдите сцену с аудио, прослушайте варианты ответа при наличии записей, откройте текст и общий перевод, выберите продолжение и завершите задания. Проверьте повтор истории, сброс тестового прохождения и открытие прямой ссылки после перезагрузки.
