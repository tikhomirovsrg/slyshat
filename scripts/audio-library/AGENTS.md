# Генерация аудио

Используется локальный Kokoro-82M; исходные тексты и список голосов принадлежат версии каталога. Модели скачиваются оператором отдельно и не коммитятся.

- Запускайте генератор с явными путями модели и голосов. Проверяйте SHA-256 весов из документации.
- Не используйте платные API без отдельной настройки оператора. Сайт должен воспроизводить опубликованные записи без ключей.
- Переиспользуемые сцены можно хранить в общих MP3 с точными временными границами. Каждый сценарий должен иметь полный порядок сцен, текст, перевод и вопросы.
- Генерация возобновляется по хешу текста, голоса, модели и параметров. Сохраняйте кэш вне Git; не считайте частично созданный набор готовым.
- Проверяйте ненулевой сигнал, частоту, конечность чисел, декодирование MP3, контрольные суммы и границы всех фрагментов.
- Не обещайте студийное качество или оценку произношения: это синтетические голоса. Отдельно указывайте отсутствие экспертного прослушивания.
- При изменении текста пересоздайте его запись и манифест. Не связывайте старую запись с новым текстом.
