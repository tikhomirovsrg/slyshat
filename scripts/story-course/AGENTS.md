# Сборка интерактивного курса

`build.py` сохраняет прежние истории и дополняет каждую языковую программу до 1000, включая 200 на уровень. Сцены из старого аудиокаталога дополняются настоящими развилками и различающимися последствиями.

- Порядок, ID и опубликованные байты `course-v1.json` неизменяемы. Для последующих изменений нужен новый выпуск и миграция, сохраняющая прогресс.
- Названия и описания должны честно отличать исходные сюжеты от вариантов с общими сценами.
- Выбор действий не превращайте в проверку угадывания правильного ответа. Каждая альтернатива должна приводить к согласованному продолжению.
- Для изменённой реплики нужна соответствующая запись. Телеметрию ONNX отключать до создания сессии; модели и кэш в Git не помещать.
- `validate.cjs` проверяет весь граф, количество и порядок, достижимость финалов, хеши и границы аудио.
